Alumni photos
=============

Put one photo per alumnus in this folder and set that person's `photo`
field in data/alumni.js, e.g. "images/alumni/jane-doe.jpg".
If the file isn't here, the card shows initials instead.

Format: square, face centred, at least 400 x 400 px, JPG under ~150 KB,
lower-case file name with words joined by hyphens.
