Scholar photos
==============

Put one photo per scholar in this folder. The page looks for the file
named in that scholar's `photo` field in data/scholars.js. If the file isn't
here, the card shows the scholar's initials instead.

Format
  - Square crop, face centred (non-square images are centre-cropped)
  - At least 400 x 400 px; around 600 x 600 px is plenty
  - JPG, under ~150 KB if possible
  - Lower-case file name, words joined by hyphens

To use a different name or format (e.g. .png or .webp), change the
`photo` value for that scholar in data/scholars.js.
